# UAMSWP Custom Editor for Learndash

This wiki documents the UAMSWP Custom Editor for Learndash plugin: which LearnDash capabilities it gives the Editor role, when it grants and removes them, and what to check when an editor's access is not what was expected.

The [README](https://github.com/UAMS-Web/UAMSWP-Learndash-User/blob/master/README.md) keeps the overview, the installation steps, and the development notes (tests, continuous integration, blame). The wiki keeps everything else.

## Reference

- [Capabilities granted](Capabilities-granted.md): every capability the plugin adds to the Editor role, grouped by LearnDash area.

## Guides

- [Activation, upgrade and deactivation](Activation-upgrade-and-deactivation.md): what the plugin does at each point in its life on a site, and how a site on an older release is brought up to date.

## Troubleshooting

- [Troubleshooting](Troubleshooting.md): an editor missing capabilities, capabilities that remain after deactivation, and the PHP version notice.
